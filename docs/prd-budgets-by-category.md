# PRD: Бюджеты по категориям

**Дата**: 2026-09-08
**Статус**: Draft

## Цель

Дать пользователю планировать расходы: задавать месячный лимит на категорию и видеть, сколько уже потрачено относительно лимита. Сейчас приложение фиксирует траты, но не позволяет их планировать.

## Пользовательские сценарии

- Пользователь задаёт месячный лимит на категорию (например, «Продукты — 50 000 ₽») → лимит сохраняется и действует каждый месяц, пока его не изменят.
- Пользователь открывает страницу «Бюджеты» → видит список категорий с лимитами и прогрессом «потрачено / лимит».
- Пользователь видит, что категория приближается к лимиту (≥ 80%) → строка помечается статусом «внимание» (янтарный).
- Пользователь видит, что лимит превышен (≥ 100%) → строка помечается статусом «перерасход» (красный) и текстом «превышен на N».
- Пользователь изменяет лимит → новое значение применяется сразу для текущего и последующих месяцев.
- Пользователь удаляет бюджет → лимит снимается, категория исчезает из списка бюджетов.

## В скоупе

- Отдельная страница «Бюджеты» (пункт в сайдбаре + маршрут).
- Создание, изменение и удаление лимита на категорию через модалку.
- Повторяющийся месячный лимит (без привязки к конкретному месяцу).
- Расчёт прогресса: сумма расходов категории за текущий календарный месяц относительно лимита.
- Три статуса: норма (< 80%), внимание (80–100%), перерасход (≥ 100%).
- Сводка месяца: итого потрачено из итого лимитов.
- Лимиты только для расходных (EXPENSE) категорий.
- Мультивалютность: лимит вводится и отображается в валюте приложения.
- Локализация интерфейса (en/ru).
- Лимиты синхронизируются между устройствами.

## Не в скоупе

- Навигация по прошлым месяцам.
- Общий месячный бюджет (не по категориям).
- История изменения лимитов / снапшоты по месяцам.
- Уведомления о приближении к лимиту.
- Бюджеты для доходных (INCOME) категорий.
- Офлайн-режим для бюджетов.

## Технические ограничения

- Лимит можно задать только для расходной категории.
- Значение лимита строго больше нуля.
- На одну категорию — максимум один лимит.
- При недоступности курсов валют суммы показываются без конвертации (как в остальном приложении).

## Критерии готовности

- [ ] На странице «Бюджеты» отображается список категорий с лимитами и прогрессом «потрачено / лимит».
- [ ] Пользователь может создать, изменить и удалить лимит через модалку.
- [ ] Лимит сохраняется между сессиями и устройствами.
- [ ] Прогресс считается по расходным транзакциям категории за текущий календарный месяц.
- [ ] Статус корректно отражает пороги < 80% / 80–100% / ≥ 100% и дублируется текстом, а не только цветом.
- [ ] Суммы отображаются в выбранной валюте приложения.
- [ ] Интерфейс переведён на en и ru.
- [ ] `npm run build` и `npm run lint` проходят без ошибок.
